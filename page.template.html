    三栏与工具栏

    左栏是文档目录（[），右栏是本篇大纲（]）。顶栏从左到右： 左栏开关、本菜单、上一篇 / 下一篇、全文搜索、打印或导出 PDF、复制当前文档链接、深浅色切换、右栏开关。

    快捷键

    [ / ]
    收起 / 展开左侧目录栏、右侧大纲栏
    /
    聚焦左栏的搜索框
    Esc
    收起搜索条 / 关闭本对话框 / 退出图表全屏
    Ctrl+P
    打印或导出 PDF

    正文宽度

    把鼠标移到正文左或右的边缘，出现竖线后按住横向拖动，正文会对称变宽变窄； 拖动时两侧竖线同时亮起，两条线之间就是当下正文的宽度。双击任一条竖线回到默认宽度。 拖出来的宽度记在本机浏览器里，优先于 config.json 的 reading.maxWidth； 上限是两侧栏之间当下还剩多少，窗口缩小或另一栏展开时会跟着收。

    全文搜索

    顶栏放大镜展开搜索条，回车在所有文档的正文里查找，结果按文档分组列出，点击跳转并高亮命中处。

    两种打开方式

    双击 md-viewer.html 是离线单文件（文档正文已内置，不联网）； node build-docs.mjs --serve 打开 index.html 是实时模式，改文档刷新即生效。
