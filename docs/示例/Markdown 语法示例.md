# Markdown 语法示例

这篇文档覆盖渲染器支持的全部语法，可以直接当"样子"看。**不支持原始 HTML**（会被转义成文本），这是为了安全。

## 1. 行内格式

普通文本、**粗体**、*斜体*、***粗斜体***、~~删除线~~、`行内代码`、[外部链接](https://example.com)。

转义写法：\*不是斜体\*、\`不是代码\`。

## 2. 标题层级

### 2.1 三级标题

#### 2.1.1 四级标题

##### 五级标题（右栏默认只收录到四级）

## 3. 列表

无序列表：

- 第一项
- 第二项
  - 嵌套项
  - 另一个嵌套项
- 第三项

有序列表：

1. 第一步
2. 第二步
   1. 子步骤
   2. 另一个子步骤
3. 第三步

任务列表：

- [x] 已经做完的事
- [ ] 还没做的事

## 4. 引用与分隔线

> 引用块可以换行，
> 也可以包含 **格式** 与 `代码`。
>
> > 还能嵌套引用。

---

## 5. 代码

行内代码：`docs/指南/快速开始.md`（这个会变成可点击的跨文档链接）。

围栏代码块（带语言标记）：

```js
export function greet(name) {
  return `你好，${name}`;
}
```

缩进代码块（四个空格）：

    markdown-docs-helper/
    ├─ md-viewer.html
    └─ build-docs.mjs

## 6. 章节引用

正文里写 §2.1 或 §5 会自动变成跳转链接 —— 前提是文档里存在对应编号的标题。
上面的 `## 2. 标题层级` 与 `### 2.1 三级标题` 因此都能被引用。

## 7. 表格

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
| 较长的单元格内容 | 短 | 123 |
| 含 \| 转义的竖线 | `code` | **粗体** |

## 8. 图片与链接

图片按相对路径解析（示例里没有真实图片文件，所以不展示）：

```markdown
![示意图](../assets/demo.png)
```

引用其它文档用相对路径或 `docs/` 前缀都行，例如 `docs/示例/表格与代码.md`。
