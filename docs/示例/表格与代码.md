# 表格与代码

这篇文档专门堆一些"容易渲染错"的内容，既是示例也是回归素材。

## 1. 宽表格（横向滚动）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | :---: | --- | --- |
| `title` | string | 否 | `"Markdown 文档浏览器"` | 顶栏主标题 |
| `subtitle` | string | 否 | `""` | 顶栏副标题，窄屏自动隐藏 |
| `home.title` | string | 否 | `"文档索引"` | 首页大标题，设成空串则不显示 |
| `home.intro` | string | 否 | `""` | 首页引导语，支持 Markdown |
| `sidebar.folders` | array | 否 | `[]` | 只显示列出的目录；空数组表示全部 |
| `toc.maxDepth` | number | 否 | `4` | 右栏收录到几级标题 |
| `reading.maxWidth` | number | 否 | `920` | 正文最大宽度（像素） |

## 3. 代码块里的陷阱

围栏里的一切都按原样输出，不解析标题和强调：

```
# 这不是标题
**这不是粗体**
| 这不是 | 表格 |
```

缩进代码块里的目录树：

    .
    ├── docs/
    │   ├── 指南/
    │   └── 示例/
    ├── test/
    └── build-docs.mjs

行内代码里出现管道符与反引号：`` `a|b` `` 、 `` `code` ``。

## 5. 长段落与中文折行

中文软换行不会插入多余空格：
这一行和
这一行在渲染后应当连成一句，中间没有空格。

英文则按空格折行：this is a long paragraph that should wrap at spaces and keep
its single spaces intact after soft line breaks.
