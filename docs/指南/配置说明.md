# config.json 配置说明

页面显示什么、长什么样，全部由工程根的 `config.json` 决定，**不用改任何一个 `.md` 文件**。
配置文件里**允许写 `//` 与 `/* */` 注释，也允许尾随逗号**，随便加说明。写错了不要紧：
页面首页会显示红色提示，并自动退回默认设置（不会白屏）。

改完之后怎么生效：

- 实时模式（`node build-docs.mjs --serve`）：**刷新页面即可**；
- 双击 `md-viewer.html`（`file://`，离线快照）：跑一次 `node build-docs.mjs`，再刷新页面。

下面按配置文件的段落顺序列出全部字段。

## 顶部与首页

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `title` | `"Markdown 文档浏览器"` | 顶栏主标题 |
| `subtitle` | `""` | 顶栏副标题，**可点击回到首页**；窄屏自动隐藏，留空则整枚按钮不显示 |
| `home.title` | `"文档索引"` | 首页大标题，设为 `""` 则不显示 |
| `home.intro` | `""` | 首页引导语，**支持 Markdown**；留空则不显示这一段 |
| `home.showCards` | `true` | 首页是否显示文档卡片列表 |

`home.intro` 里写 `docs/示例/快速开始.md` 会自动变成可点击的跳转链接，例如：

```jsonc
"home": {
  "title": "文档索引",
  "intro": "## 使用须知\n\n本页只读展示，不改文档。\n\n- 左栏：`[` 开关\n- 详细说明见 `docs/指南/快速开始.md`",
  "showCards": true
}
```

## 左侧目录栏

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `sidebar.title` | `"文档目录"` | 左栏标题 |
| `sidebar.defaultOpen` | `false` | 默认是否展开（窄屏一律默认收起） |
| `sidebar.remember` | `true` | 是否记住上次的开关状态 |
| `sidebar.showSearch` | `true` | 是否显示搜索框 |
| `sidebar.showCounts` | `true` | 分组名右侧是否显示篇数 |
| `sidebar.folders` | `[]` | 只显示列出的目录，并按此顺序排列；**空数组 = 显示全部目录** |
| `sidebar.exclude` | `[]` | 额外排除的目录前缀或单个文件路径 |
| `sidebar.order` | `[]` | 让指定文档排在前面（按数组顺序） |
| `sidebar.docs` | `{}` | 单篇覆盖：隐藏某篇，或改它的显示标题（都不动 md 文件） |

`folders` 的两种写法（`label` 是显示名，可随意改成中文）：

```jsonc
"folders": [
  { "dir": "docs/指南", "label": "指南" },
  { "dir": "docs/示例", "label": "示例" }
]
```

单篇隐藏与改名：

```jsonc
"docs": {
  "docs/示例/表格与代码.md": { "hidden": true },          // 不在左栏与首页出现
  "docs/指南/快速开始.md": { "title": "改过的显示名" }     // 只改显示标题
}
```

被 `hidden` 隐藏的文档**仍然可以通过正文里的 `docs/xxx.md` 引用打开**（只是不列出来、搜索结果里也不出现）。

> `folders` / `exclude` / `docs` 里的路径都带 `docs/` 前缀。这个前缀是**虚拟前缀**，与真实目录名无关：
> 用 `node build-docs.mjs --serve D:\proj\docs` 指到别处时，`D:\proj\docs\设计\x.md` 的路径仍然是
> `docs/设计/x.md`，所以配置文件不用跟着改。

## 右侧目录栏与阅读区

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `toc.title` | `"本篇目录"` | 右栏标题 |
| `toc.defaultOpen` | `true` | 默认是否展开（当前默认：只开右侧栏） |
| `toc.remember` | `true` | 是否记住上次的开关状态 |
| `toc.maxDepth` | `4` | 右上目录收录到几级标题（`2` 只到二级，`3` 到三级，`4` 最多四级） |
| `reading.maxWidth` | `920` | 正文最大宽度（像素）。嫌一行太长就调小，嫌窄就调大；页面上也可以直接拖正文左右边缘调（向外拖对称变宽），**拖过的宽度记在本地、压过这个值**，双击那条边就回到这里写的数 |

## 正文里的 HTML（`markdown.html`）

Markdown 正文里写的 HTML 标签怎么处理。**代码围栏与行内代码里的 HTML 永远是源码文本**，
三种模式都不动它们；`docs/xxx.md` 引用、`§` 章节引用、左栏摘要、右栏目录在三种模式下也照常可用。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `markdown.html` | `"escape"` | `escape` 转义显示 / `innerhtml` 原样输出交给浏览器渲染 / `strip` 吃掉标签只留内容 |

```jsonc
"markdown": {
  "html": "escape"   // escape（默认）/ innerhtml / strip，认不出的值按 escape 处理
}
```

- **`escape`（默认）**：`<div class="note">` 原样显示成这行文字，文档安全，与以前的行为完全一致。
- **`innerhtml`**：浏览器真去渲染这些标签，可写 `<details>` 折叠块、`<span style>` 着色等。
  代价是文档获得页面全部权限——**只对完全可信的文档开**（`innerHTML` 插入的 `<script>` 不会执行，
  但属性里的事件如 `<img onerror=…>` 会执行）；块级标签与 Markdown 混排时行距可能不太整齐，
  页面已把多出来的空段落隐藏掉。
- **`strip`**：`<div class="note">…</div>` 只剩里面文字，按普通 Markdown 排版；
  `<br>` 变换行（表格单元格里也生效）、`<img>` 变图片（相对路径照常解析成文档目录下的文件）、
  HTML 注释与 `<script>`/`<style>` 连内容一起消失、实体（`&amp;`、`&nbsp;`、`&#65;` 等）还原成字符；
  `a < b`、`<user@example.com>` 这类不是标签的写法不会被误吃。想统一套壳、又不想让标签影响排版时用它。

## 思维导图（`.mermaid`）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `mindmap.enabled` | `true` | 总开关。设成 `false` 后 `.mermaid` 只当普通文本显示，左栏也不再标「导图」 |
| `mindmap.extensions` | `[".mermaid"]` | 哪些后缀按思维导图渲染（写 `"mermaid"` 或 `".MERMAID"` 都认） |
| `mindmap.initialExpandLevel` | `2` | 打开时展开到第几层：`1` 只展开一级分支，`2` 再展开一层，`0` 全部展开，`-1` 全部折叠 |
| `mindmap.showOutline` | `true` | 右栏是否显示导图大纲（可点击定位、点三角折叠） |
| `mindmap.exportImage` | `true` | 是否显示导图工具栏上的 SVG / PNG 导出按钮 |

```jsonc
"mindmap": {
  "enabled": true,
  "extensions": [".mermaid"],
  "initialExpandLevel": 2,
  "showOutline": true,
  "exportImage": true
}
```

`.mermaid` 文件里写的**不是** `mindmap`（比如 `stateDiagram-v2`）时，会自动改走下面的图表引擎，
左栏标记从「导图」变成「图表」，右栏标题也变成「图表」。

## 嵌入的 Mermaid 图表（mermaid 围栏）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `mermaid.enabled` | `true` | 总开关。设成 `false` 后 mermaid 围栏退回普通代码块；离线产物里也不再内联那 3 MB 引擎 |
| `mermaid.theme` | `"auto"` | 图表主题：`auto` 跟随页面深浅色（切主题会重画），也可写 `default` / `dark` / `forest` / `neutral` / `base` |
| `mermaid.style` | `"doc"` | 观感：`doc` = 文档风（圆角浅紫状态胶囊 + 深紫描边 + 深灰连线 + 不透明浅灰标签底片 + 缩小加描边的箭头，顺带把流程图节点与连线的线宽也统一），`plain` = mermaid 原样。深浅色各有一套配色，导出的 SVG 自带这套样式 |
| `mermaid.securityLevel` | `"strict"` | `strict` 时图表标签里的 HTML 被转义（与「正文不解析原始 HTML」一致）；文档可信、确实需要 `<br/>` 换行时才改 `loose` |
| `mermaid.controls` | `true` | 每张图右上角的工具栏（源码 / 复制 / SVG / 全屏） |
| `mermaid.exportImage` | `true` | 工具栏里是否给「SVG」导出按钮 |
| `mermaid.fullscreen` | `true` | 工具栏里是否给「全屏」按钮 |

```jsonc
"mermaid": {
  "enabled": true,
  "theme": "auto",
  "style": "doc",
  "securityLevel": "strict",
  "controls": true,
  "exportImage": true,
  "fullscreen": true
}
```

关于 `style`：`doc` 是默认值，效果就是 `docs/示例/状态图版式对照.md` 里那几张图的样子。
它只在**形状**上动刀（圆角半径、描边与连线粗细、标签底片的不透明度、箭头尺寸），
配色仍然全部来自 `theme` / `themeVariables`，所以换 `theme` 或切深浅色都不会打架；
不想要这套观感就写 `"style": "plain"`，图会退回 mermaid 自带的外观（`rx=5`、1px 线、半透明标签底片）。

箭头的微调（`doc` 把倒钩缩到约 2/3 并补一圈 1.1px 描边，读起来更接近实心小三角）有两处容易踩空，
改这块代码前值得先看一眼 `assets/md-app.js` 里 `mgTuneMarkers` 的注释：引擎每个 marker 类型都会
emit 两个 id，**连线实际引用的是带 `-margin` 后缀的那个、而且它不在 `<defs>` 里**；另外 marker 的
视口（`markerWidth`/`markerHeight`）本身就是裁剪框，只把视口改小会把箭头的尖切掉。`doc` 与 `plain`
的箭头尺寸差别（约 2/3）有回归断言守着，见 `test/mermaid-style-ui.mjs`。

字段改错（例如写成别的字符串）会退回 `doc`，不会报错。改完实时模式刷新即可看到效果。

关于体积：离线单文件 `md-viewer.html` 只在**这批文档真的用到了** Mermaid 图表时（正文里有
mermaid 围栏，或 `.mermaid` 文件写的是整篇图表）才把 `vendor/mermaid/mermaid.min.js`
内联进去；没用到时页面里只留一个空引擎块，文件仍是 1 MB 上下，围栏也会显示成普通代码块。
实时版（`--serve`）始终按本地外链加载，按需即用。

语法写错时那块会显示一条含 Mermaid 报错的提示，并自动摊开源码；同一篇文档里其它图表不受影响。
可运行的例子见 `docs/示例/Mermaid 图表.md`，整篇图表见 `docs/示例/状态机示例.mermaid`。
