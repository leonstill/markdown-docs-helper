# 界面与快捷键

本页讲页面长什么样、每个按钮做什么、键鼠怎么操作。

页面本身有两个形态，**界面完全一致**（都由 `build-docs.mjs` 从 `page.template.html` 生成），
差别只在数据来源与刷新方式：

| 打开方式 | 页面 | 数据来源 | 改了文档 / 配置之后 |
| --- | --- | --- | --- |
| `node build-docs.mjs --serve` 实时模式（`http://127.0.0.1:8899/`，加 `--lan` 可给局域网内其它机器看） | `index.html` | 直接读文档目录下的文档与 `config.json` | **刷新页面即可**，新增文档也不用重建 |
| 双击 `md-viewer.html`（`file://`） | `md-viewer.html` | 页面内置的文档（`.md` + `.mermaid`）与配置副本 | 跑一次 `node build-docs.mjs`，再刷新页面 |

两个页面只有两处不同：实时版把四个引擎（markmap 导图、mermaid 图表）换成本地外链
`<script src="vendor/markmap/*.js">` / `<script src="vendor/mermaid/mermaid.min.js">`（浏览器可缓存），
并把内置快照置空（实时模式每次刷新都去读 `docs-index.json`，留一份旧副本只会误导）。
离线版则把引擎整段内联进页面（其中 mermaid 有 3 MB，只在文档里真的用到了图表时才内联）。

## 三栏布局

- **左侧目录栏**：全部文档，可搜索、可分组；显示哪些文档由 `config.json` 决定
- **中间正文**：Markdown 渲染结果，表格可横向滚动，代码块带边框
- **右侧目录栏**：当前文档的标题大纲，滚动时自动高亮所在章节

两侧栏都可以独立隐藏，并且记住上次的开关状态。

## 工具栏

| 按钮 | 位置 | 作用 |
| --- | --- | --- |
| 侧栏开关（图标） | 最左 | 开关左侧目录栏（快捷键 `[`） |
| 上一篇 / 下一篇 | 左半区 | 按左栏顺序切文档 |
| 打印 | 中间 | 打印 / 导出 PDF（等价于 `Ctrl+P`） |
| 链接 | 中间 | 复制当前文档链接（带文档与章节位置） |
| 深色 / 浅色 | 中间 | 切换配色，跟随系统偏好并记住选择 |
| 侧栏开关（图标） | 最右 | 开关右侧目录栏（快捷键 `]`） |

## 页面操作

| 操作 | 方式 |
| --- | --- |
| 开关左侧目录栏 | 工具栏最左侧按钮，或快捷键 `[`，或左栏右上角 `✕` |
| 开关右侧目录栏 | 工具栏最右侧按钮，或快捷键 `]`，或右栏右上角 `✕` |
| 搜索 | 左栏搜索框（文件名 + 全文），快捷键 `/` 聚焦，`Esc` 清除 |
| 打开文档 | 点左栏条目、点首页卡片，或直接点正文里 `docs/xxx.md` 形式的引用 |
| 跳转章节 | 点正文里的 `§5.3` 这类引用，或点右栏目录 |
| 跨文档跳转 | 正文里 `` `docs/指南/快速开始.md` `` 形式的行内代码（写法见根目录 `README.md` 的「跨文档章节引用」） |
| 上一篇 / 下一篇 | 工具栏按钮（顺序与左栏一致） |
| 切换深 / 浅色 | 工具栏「深色 / 浅色」按钮（跟随系统偏好，且记住选择） |
| 打印 / 导出 PDF | 工具栏「打印」，或 `Ctrl+P` → 目标选「另存为 PDF」 |
| 复制当前文档链接 | 工具栏「链接」（链接带文档与章节位置，可直接发给别人） |
| 导图 / 图表全页面显示 | 导图或图表工具栏的「全屏」按钮（见下文「思维导图操作」「嵌入的 Mermaid 图表」） |

侧栏的开关状态会记住（默认开启记忆，可在 `config.json` 的 `sidebar.remember` / `toc.remember` 里关掉）。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `[` | 开关左侧目录栏 |
| `]` | 开关右侧目录栏 |
| `/` | 聚焦搜索框 |
| `Esc` | 清空搜索并失焦；导图 / 图表全屏时退出全屏 |
| `Ctrl` + `P` | 打印 / 导出 PDF |

## 窄屏行为

窗口宽度小于 860px 时，两侧栏变成抽屉：默认都收起，点工具栏按钮滑出，
点空白遮罩或右上角 `✕` 收起。顶栏会隐藏副标题与路径以节省空间。

## 思维导图操作

| 操作 | 方式 |
| --- | --- |
| 缩放 / 平移 | 滚轮缩放、拖拽平移；双击画布或点「适应」回到合适大小 |
| 折叠 / 展开节点 | 点节点本身（也可以直接点图上的小圆圈） |
| 整体折叠 / 展开 | 工具栏「折叠」按钮 |
| 跳到大纲某项 | 点右栏「导图大纲」里的条目（会展开路径并把该节点移到视野中） |
| 只折叠某个分支 | 点大纲条目前面的小三角（▾ / ▸） |
| 导出图片 | 工具栏「SVG」或「PNG」（PNG 会按当前主题带底色；导出按钮由 `config.json` 的 `mindmap.exportImage` 控制） |
| 打印 / 导出 PDF | 工具栏「打印」——导图会整体输出，不是只打印可视区域 |
| 全页面显示 | 导图工具栏「全屏」：铺满整个浏览器窗口，再点一次或按 `Esc` 还原（`F11` 也能叠加使用） |

`.mermaid` 文件的语法支持范围见根目录 `README.md` 的「思维导图（Mermaid mindmap）」一节。

## 嵌入的 Mermaid 图表（mermaid 围栏）

正文里用信息串为 `mermaid` 的围栏写的图，右上角会有一条小工具栏：

| 操作 | 方式 |
| --- | --- |
| 看 / 改源码 | 点「源码」就地摊开，再点一次收起（语法错时会自动摊开） |
| 复制源码 | 点「复制」，贴到别处改；按钮会短暂变成「已复制」 |
| 导出 SVG | 点「SVG」，导出的是自包含文件（含当前主题配色与底色，单独打开也正常） |
| 全页面显示 | 点「全屏」：这张图铺满窗口，并**按比例放大到放得下的最大尺寸**（宽图顶满宽度、高图顶满高度，另一轴居中留白），页面滚动被锁住，再点一次或按 `Esc` 还原；切换文档会自动退出 |
| 换主题重画 | 工具栏的深 / 浅色按钮——mermaid 的主题是画进 SVG 里的，所以会整篇重画一遍 |

工具栏按钮可以用 `config.json` 的 `mermaid.controls` / `exportImage` / `fullscreen` 分别收起来；
整体关闭（围栏退回普通代码块）用 `mermaid.enabled`。各类版式的写法示例见 `docs/示例/Mermaid 图表.md`。

## 页面上的状态提示

- **左栏底部**：显示按 `config.json` 过滤后的「当前显示 N 篇」（被过滤时才出现）、
  被忽略的非 Markdown 文件数量，以及一行**数据来源**——「实时读取 docs/」还是「离线快照（时间）」；
- **左栏底部**还有一行快捷键提示（`[/]` 左右栏 · `/` 搜索 · `Esc` 清除 · `Ctrl+P` 打印）；
- **首页那行小字**同样写明当前是实时读取还是离线快照，避免把旧内容当成最新；
- 搜索时左栏顶部会显示「搜索结果 N 篇」，清空搜索框即回到目录。

快照是不是旧的不用猜：`node build-docs.mjs --check` 判断产物是否已过期（过期退出码为 1），
适合接在提交前检查里；不确定差在哪时用 `node test/why-stale.mjs` 会把差异逐条列出来。

## 侧栏开关的实现要点

侧栏收起用的是「左栏负外边距滑出、右栏收窄裁剪」两套做法，都是为了在**不重排正文**的前提下把空间收干净：

- 左栏：`margin-left: calc(-1 * var(--left-w))`，左向溢出不会产生横向滚动条；
- 右栏：`width` 收窄到 0 并自己裁剪，内层保持原宽，视觉上同样向右滑出；右栏的纵向滚动下沉到内层列表，
  避免滚动条裁掉固定宽度的内容。

动画首帧用 `html.preload` 关掉过渡，避免加载时侧栏"滑一下"。

## 导图全屏的实现要点

「全屏」不是 `requestFullscreen()`，而是给导图容器加 `.mm-full`：`position: fixed; inset: 0; z-index: 60`，
铺满整个浏览器窗口并盖住顶栏与两侧栏（顶栏 `40`、侧栏 `35`、窄屏遮罩 `30`，所以取 `60`）。
这样做的好处是 `file://` 下不需要用户手势授权，退出也不受浏览器自身全屏状态（`F11`）影响；
同时在根元素上挂 `mm-full-on` 锁住底层滚动，退出时不会"跳回顶部"。
切换后容器的尺寸变了，`fit()` 读的是 SVG 的 `getBoundingClientRect`，所以要在下一帧和稍后各重适配一次。
打印时 `.mm-full` 会退回普通文档流，否则 `fixed` 覆盖层会把内容裁在一页里。

## 图表全屏的实现要点

覆盖层那套与导图一样（`.mg-full` + 根元素上的 `mg-full-on` 锁滚动），区别在「图怎么变大」：
导图是画在 canvas 上的，进出全屏后要调 `fit()` 重适配；嵌入的 Mermaid 图是 SVG，纯 CSS 就够——
让 `.mg-body` / `.mg-host` 吃满窗口，再把 `svg` 撑成容器的 `100%×100%`，SVG 自带的 `viewBox` 与
`preserveAspectRatio="xMidYMid meet"` 会自己等比缩放到装得下为止，窗口缩放也不用再量一次。

两个坑都写在 `assets/viewer.css` 那一段的注释里：mermaid 的 `svg` **没有 intrinsic 宽高**，
只写 `max-width:none` 会退回替换元素默认的 `300×150`（图反而比文档视图里还小，这就是「全屏后图很小」的成因）；
而且它把 `max-width` 写在 `style` 内联属性上，不用 `!important` 压不住。
打印样式也要用 `!important` 把全屏那套尺寸压回去（`height:100%` 在静态文档流里会塌成 0）。
