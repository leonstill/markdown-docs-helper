# 正则表达式

搜索条最前面的 `.*` 按钮（或 `Alt` + `R`）打开正则表达式模式。
开关打开后，按钮保持按下状态，输入框里的提示语也会变成正则模式说明。

正则模式把**整串输入当作一个 JavaScript 正则**来用。它和普通关键词组合是两套规则：
正则模式下，空格、`&&`、`||`、`!` 都只是普通字符，不再有「或 / 与 / 非」的含义。

## 匹配规则

- 正则按 `new RegExp(输入, 'gi')` 编译：**不区分大小写**，并且在一行里找出**所有**命中。
- 仍然**按行匹配**：`.` 不会跨过换行，`^` / `$` 是行首与行尾，一条模式不能跨行。
- 输入就是模式本身，不要写 `/.../gi`；开头的 `/` 和结尾的 `/i` 会被当成普通字符。
- 正则写错时不会乱搜：输入框标红，结果页显示「正则表达式无效：…」，改到正确为止即可。
- 零长度匹配（例如只写 `^`、`\b`、`a*`）没有可标出的文字，不会列成结果；
  让模式至少吃进一个字符，比如 `^#`、`\bTODO\b`。

## 常用语法

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `.` | 任意一个字符（换行除外） | `a.c` 命中 abc、a-c |
| `\d` / `\D` | 数字 / 非数字 | `v\d+` 命中 v1、v22 |
| `\w` / `\W` | 字母数字下划线 / 其它 | `\w+` 命中单词 |
| `\s` / `\S` | 空白 / 非空白 | `foo\s+bar` 命中 foo 与 bar 间有空白 |
| `\b` | 单词边界 | `\bTODO\b` 不会命中 TODOS |
| `^` / `$` | 行首 / 行尾 | `^## ` 命中二级标题行 |
| `[...]` | 字符集合；`^` 在开头表示取反 | `[aeiou]`、`[^0-9]` |
| `(...)` | 分组 | `(foo\|bar)baz` |
| `(?:...)` | 只分组、不捕获 | `(?:TODO\|FIXME)` |
| `\|` | 或 | `mermaid\|markmap` |
| `*` `+` `?` | 前一项 0 次以上 / 1 次以上 / 0 或 1 次 | `ab*c`、`ab+c`、`ab?c` |
| `{n}` `{n,m}` | 前一项重复次数 | `\d{4}-\d{2}` |
| `\` | 转义下一个字符 | `\.` 命中字面点号 |

表格里的 `\|` 是为了不被当成表格分隔符；输入框里直接写 `|` 即可。

## 常用例子

```text
\bTODO\b             只找独立的 TODO
(TODO|FIXME)         找 TODO 或 FIXME
^#{2,3}\s            找二级或三级标题行
v?\d+\.\d+\.\d+      语义化版本号，如 1.2.3 / v2.0.1
20\d{2}-\d{2}-\d{2}  日期样式，如 2026-10-29
[a-z]+_[a-z]+        下划线分隔的标识符
```

## 与普通模式的区别

| | 普通模式 | 正则模式 |
| --- | --- | --- |
| 输入含义 | 空格 / `\|\|` 或、`&&` 与、`!` 非 | 整串是一个 JavaScript 正则 |
| 空格 | 分隔关键词 | 字面空格 |
| 大小写 | 不区分 | 不区分 |
| 跨行 | 单个词不能跨行；`&&` 的条件可以分布在不同行 | 不能跨行 |
| 写错时 | 提示运算符或否定词的问题 | 提示「正则表达式无效」 |
| 结果与跳转 | 命中行分组列出，可点进文档高亮 | 相同；链接会多带 `&re=1`，确保原样重跑同一条正则 |

## 容易踩的坑

- **字面符号要转义**：想找 `.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `\` 时，
  前面加 `\`，例如 `\.`、`\(`。
- **反斜杠只写一层**：输入框里写 `\d`，不要写成 `\\d`；写两层表示「字面反斜杠 + d」。
- **不要包 `/.../`**：`/foo/` 在这个输入框里找的是带斜杠的文本，不是正则字面量。
- **空格不是「或」**：正则模式里 `foo bar` 只命中连续的「foo bar」；想表达或请写 `foo|bar`。
- **不用加 `i` 标志**：默认已经是不区分大小写，也没有写标志的位置。
- **别写只匹配空字符的模式**：`^`、`$`、`a*` 这类零长度结果不会列出；补上要匹配的内容。
- **过宽的模式会撞结果上限**：`.` 或 `\w` 几乎命中每一行，结果页单篇最多列 40 处、
  整页最多 400 处；把模式写具体一些。
