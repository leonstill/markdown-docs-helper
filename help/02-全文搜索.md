# 全文搜索

顶栏放大镜展开搜索条，回车在所有文档的正文里查找，结果按文档分组列出，点击跳转并高亮命中处。

## 打开与收起

- 点顶栏放大镜：展开搜索条并聚焦输入框；再点一次收起。
- 输入框里按 `Esc`：收起。
- 输入框**没有内容**时，点页面其它地方会自动收起；已经输入了关键词就不会被点走。
- 搜索条最前面的 `.*` 按钮（或 `Alt` + `R`）切换正则表达式模式，详见顶部「正则表达式」页。

## 输入框前后的按钮

| 按钮 | 作用 |
| --- | --- |
| `.*` | 切换正则表达式模式（`Alt` + `R`） |
| `✕` | 清空输入和正文里的高亮，焦点留在输入框 |
| 放大镜 | 提交搜索（等同于回车），结果开在正文区 |

## 普通模式的关键词语法

| 写法 | 含义 |
| --- | --- |
| `alpha beta` 或 `alpha \|\| beta` | 含 alpha **或** beta（空格就是默认的「或」） |
| `alpha && beta` | 含 alpha **且** beta；两个词可以出现在同一篇的不同行 |
| `alpha && !draft` | 含 alpha，且整篇都不出现 draft |
| `a && b \|\| c` | `&&` 优先级高于 `\|\|`，等价于 `(a && b) \|\| c` |
| `R&D`、`a\|b` | 单个 `&` / `\|` 是普通字符，不用转义 |

反斜杠转义下一个字符，用来搜运算符本身，或者搜带空格的短语：

```text
a\&\&b       搜字面的 a&&b
\!important  搜字面的 !important
foo\ bar     搜含空格的 "foo bar"
```

优先级固定为 `!` > `&&` > `||`，不支持括号。`!` 只能用来排除：每个「或」分支都必须有正向关键词。
查询写错（悬空运算符、纯否定）时输入框标红，正文区会给出具体原因。

## 结果页

搜索范围是程序启动时导入的全部文档原文，不区分大小写。结果按文档分组，从上到下依次是：
标题命中的文档、其余按导入顺序。每条结果给出所在章节、行号与上下文，命中处用底色标出；
单篇最多列 40 处、整页最多 400 处。

左栏会临时换成「命中文件导航」（每篇一条：标题 + 处数 + 路径），点一条把视口滚动到正文里对应的那一组。
点任意一条结果会打开那篇文档、滚到那一处命中，并把正文里所有命中处标上底色。

搜索条的开合状态记在浏览器历史里（每条历史记录各存一份，不进地址栏），前进 / 后退会还原成当初的样子。
