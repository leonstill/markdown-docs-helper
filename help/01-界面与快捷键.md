# 界面与快捷键

本页讲页面长什么样、键鼠怎么操作、正文宽度怎么调。

## 三栏与工具栏

左栏是文档目录（`[`），右栏是本篇大纲（`]`）。顶栏从左到右：
左栏开关、品牌菜单、上一篇 / 下一篇、全文搜索、打印或导出 PDF、复制当前文档链接、深浅色切换、右栏开关。

按住两侧栏与正文之间的分界线左右拖，可以调这一栏的宽窄；双击那条缝复原。
向下滚过一段后，正文右下角会浮出圆形 ↑ 按钮，点一下滚回顶部。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `[` / `]` | 收起 / 展开左侧目录栏、右侧大纲栏 |
| `/` | 聚焦左栏的搜索框 |
| `Esc` | 收起搜索条 / 关闭对话框 / 退出图表全屏 |
| `Ctrl` + `P` | 打印或导出 PDF |
| `Alt` + `R` | 切换顶栏搜索条的正则表达式模式 |

## 正文宽度

把鼠标移到正文左或右的边缘，出现竖线后按住横向拖动，正文会**对称**变宽变窄；
拖动时两侧竖线同时亮起，两条线之间就是当下正文的宽度。双击任一条竖线回到默认宽度。

拖出来的宽度记在本机浏览器里，优先于 `config.json` 的 `reading.maxWidth`；
上限是两侧栏之间当下还剩多少，窗口缩小或另一栏展开时会跟着收。
